Yêu cầu môi trường: Cần cài Visual Studio 2022, .NET 8.

Hướng dẫn chạy:

Bước 1: Mở file .sln trong thư mục Code/ bằng Visual Studio.

Bước 2: Chuột phải vào project Server -> Set as Startup Project -> Bấm Run.

Bước 3: Chuột phải vào project Client -> Set as Startup Project -> Bấm Run.
